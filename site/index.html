Saku web vault

Development preview. Not audited. Try it with the demo vault. Do not put real passwords in it yet. This page is not Saku Android and does not sync with it.

It opens and edits KeePass-format (KDBX 4) files on this device. The file stays in this tab: nothing is uploaded and nothing is saved in the browser. Save with the Save button, which downloads a new file. The page loads no outside scripts and can only contact its own site (to fetch the demo file).

Open a vault

Demo vault password: demo-not-real (fake entries only).

Or start a new vault

There is no recovery. If you forget the master password, the file cannot be opened.

    The vault locks itself after 5 minutes without use. Copied passwords are cleared from the clipboard after 30 seconds if the browser allows it.

    Source · Android demo · Built with kdbxweb and hash-wasm (both MIT, see vendor/).
